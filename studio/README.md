# Studio

Shared workspace for the content agents. Every agent reads from and writes to these paths.

- `MVP.md` — app concept. Plugs must match a feature listed here.
- `brand/` — name options, logo sheet, palette.
- `topics.md` — topic bank (research agent, Day 2).
- `scripts/` — scripts as JSON + markdown (script agent).
- `factcheck/` — one file per script, a claim-by-claim table with sources. A script without a pass does not render.
- `audio/` — voiceover and SFX.
- `renders/` — Remotion output, 1080x1920 at 30fps.
- `ready/` — approved packages: MP4, caption, hashtags, post time. The founder posts. Nothing gets auto-posted.
- `metrics.csv` — daily stats (analyst).

Status: Day 1. Waiting for the founder to sign off the brand and MVP before the Remotion build.
