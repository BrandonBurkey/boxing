Rough marks: `studio/brand/logo-sheet.png`. These are concepts, not final art.

**How the handles were checked (2026-10-26):** a plain request to `tiktok.com/@handle` for each one.
A handle that doesn't exist returns status `10221` ("user not found"). A made-up control handle
returned 10221 and `@jabmaxapp` did not, so the check works. "Free" means no account was found at
check time. It is not a reservation. **Register your pick today**, because handles can be taken at any
time. TikTok may also block some names it holds back, so the real test is the sign-up screen.

**Recommendation: 1 (Angle Theory) or 3 (Outfox).**
- Angle Theory matches the visual format best: every video is lines, angles and geometry.
- Outfox is the best fit for the insecurity reframe: you don't need to be bigger, you need to be smarter.
- Web searches found no existing boxing app under either name. These were quick name searches, not a
  trademark search. Run a UK IPO / USPTO check before you print anything.

**Distinct from JabMax:** no "Jab" or "Max" in any name. Each option has its own accent colour, and
the mannequin design will follow our palette. I could not open the JabMax videos, so please check
your screenshots and tell me if any accent above is close to theirs. I'll swap it if so.

Mannequin palette (all options): "YOU" = warm off-white body `#EDE6DA` + brand-accent gloves;
opponent = slate `#4A5260` body + muted dark-red gloves `#8C2F2F`; background `#0D0F12` with a
`#1B1F25` grid.
